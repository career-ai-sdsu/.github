# Career AI | SDSU Student Project

We are a student project team developing AI-powered tools for career development and job-search workflows.

Our Fall 2026 project focuses on building a **Resume / Job Description Gap Analyzer** that helps users understand how well a resume aligns with a specific job posting.

## Current Project

### Resume / JD Gap Analyzer

The tool is being designed to compare a resume against a job description and identify:

- Matching skills and qualifications
- Missing or underrepresented skills
- Experience and requirement gaps
- Overall resume-to-job alignment

## Project Workflow

We are following the machine learning workflow introduced through the SDSU AI Club:

**Business Understanding → Data Understanding → Data Preparation → Modeling → Evaluation → Deployment**
