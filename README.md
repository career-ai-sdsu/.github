# .github

Organization-wide GitHub configuration for **Career AI | SDSU Student Project**.

This repository contains shared GitHub resources used across projects in the `career-ai-sdsu` organization.

## Contents

- `profile/README.md` — Organization profile shown on the Career AI GitHub page
- `ISSUE_TEMPLATE/` — Shared issue templates
- `PULL_REQUEST_TEMPLATE.md` — Shared pull request template
- `CONTRIBUTING.md` — General contribution guidelines
- `CODE_OF_CONDUCT.md` — Community and collaboration guidelines

Additional organization-wide configuration may be added as the project develops.

## Current Project

Our current Fall 2026 project is the **Resume / JD Gap Analyzer**, an AI-powered tool for comparing resumes against job descriptions and identifying relevant skill, qualification, and experience gaps.
