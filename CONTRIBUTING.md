# Contributing

Thanks for contributing to Career AI projects.

## Workflow

1. Create a branch from `main`.
2. Make a focused set of changes.
3. Commit with a short, descriptive message.
4. Push your branch and open a pull request.
5. Request review from at least one teammate.
6. Address feedback before merging.

## Branch Names

Use short, descriptive names such as:

- `feature/resume-parser`
- `feature/skill-matching`
- `fix/pdf-extraction`
- `docs/readme-update`

## Commits

Keep commits focused and use clear messages, for example:

- `Add PDF text extraction`
- `Implement baseline skill matching`
- `Fix duplicate skill detection`

## Pull Requests

Pull requests should explain:

- What changed
- Why the change is needed
- How the change was tested
- Any remaining questions or follow-up work

Keep pull requests reasonably small when possible so they are easier to review.

## Data and Privacy

Do not commit real resumes, private job-application data, API keys, credentials, or other sensitive information.

Use synthetic or appropriately anonymized sample data for development and testing.
